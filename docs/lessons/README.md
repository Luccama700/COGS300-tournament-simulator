# Lessons — the project's memory across agent sessions

One lesson per file, with a one-line summary as the first line. Record
corrections and confirmed approaches alike, including why they mattered.
Don't save what the repo or `docs/EXPERIMENTS.md` already records; update an
existing note rather than creating a duplicate; delete notes that turn out
to be wrong.

Read every file here at the start of a session. Each seeded lesson below
cost at least one failed experiment; the full stories are in
`docs/PROJECT_GUIDE.md`.
